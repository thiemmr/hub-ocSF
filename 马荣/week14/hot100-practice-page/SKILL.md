# Hot 100 刷题页生成器

生成一个无需构建工具、可直接用浏览器打开的静态答题网页。默认模板位于 `assets/template/index.html`，生成脚本位于 `scripts/create_practice_page.py`。

## 工作流

1. 确认输出目录；用户未指定时，在当前工作区创建 `hot100-practice-page`。
2. 运行：

   ```powershell
   python <skill-dir>/scripts/create_practice_page.py <output-dir>
   ```

   使用 `--title "标题"` 可替换默认页面标题。目标目录中若已有 `index.html`，脚本会停止，除非显式传入 `--overwrite`。
3. 按用户要求定制生成后的 `index.html`，不要直接修改 Skill 内模板，除非用户明确要求更新 Skill。
4. 验证页面：抽查题目卡完整显示题目描述、输入、输出、约束和示例；题面不显示分类和难度；100 题总览完整且未练习为白色、已练习为特殊颜色、错题有独立标识；总览可按状态筛选并点击跳题；错题本可加入、移出且刷新后保留；随机切题不连续重复；切题、切换语言或刷新后，代码与思路仍能从 `localStorage` 恢复；页面中不存在运行、提交、测试或正确性校验功能。
5. 交付生成的网页文件，并说明可直接双击 `index.html` 使用。

## 产品约束

- 保持纯前端、零依赖、单文件，默认不需要网络；官方题面链接除外。
- 每道题必须在网页内提供可独立作答的原创完整重述，包括任务规则、输入、输出、关键约束和至少一个自写示例；不能只显示一句摘要或要求用户跳转到外部网站才能理解题目。
- 不要逐字复制力扣或其他来源的完整题面、示例或长段受版权保护内容。用自己的语言重述，并保留官方题面链接供核对。
- 将每道题、每种语言的草稿分别存入浏览器 `localStorage`。
- 提供可查看全部 100 道题的练习状态总览：未练习题使用白色标记，已练习题使用清晰的特殊颜色；题目可点击跳转，并可按全部、未练习、已练习和错题本筛选。
- 使用 `hot100:practiced:<题号>` 保存练习标记，使用 `hot100:wrong:<题号>` 保存错题本状态；两者互相独立，刷新或重新打开页面后均须恢复。
- 在答题区提供“加入错题本/移出错题本”操作，并在 100 题总览中用独立于练习状态的醒目标识展示错题。
- 默认隐藏题目卡上的分类和难度徽标；分类和难度筛选控件仍可保留。
- 明确展示“仅保存草稿，不运行或校验代码”。不要添加隐藏判题、远程提交或代码执行请求。
- 随机选择须尊重当前筛选，并尽量避免与上一题相同；筛选结果为空时给出可理解的提示。
- 保持键盘可用性、清晰焦点样式、移动端适配和足够的颜色对比度。

## 定制原则

- 若用户只要求生成页面，优先保留模板已有交互和视觉层级。
- 若用户要求增删题目，同时编辑页面中的 `problems` 与 `problemDetails` 数据，并更新页面显示的题目总数；新增题目也必须满足完整题意标准。
- 若用户要求加入计时或收藏，继续使用 `localStorage`；练习标记和错题本状态都不得表达成“答案正确”或自动判题结果。
- 若用户要求运行或判题，先说明这超出本 Skill 的既定范围，再在获得明确同意后改用合适的执行架构。
