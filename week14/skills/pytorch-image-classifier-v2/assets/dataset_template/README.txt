Dataset Template
================
Copy this directory and place your images into the class subdirectories.
Then remove this file and the .gitkeep files.

Structure:
  dataset/
    train/
      class_a/  <- training images for class A
      class_b/  <- training images for class B
    val/
      class_a/  <- validation images for class A
      class_b/  <- validation images for class B

Supported formats: .jpg, .jpeg, .png, .bmp, .tiff, .webp
